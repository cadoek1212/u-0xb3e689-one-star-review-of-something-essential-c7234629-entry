One deadpan one-star review of water, picked by a deterministic scorer from 10 original candidates against the judge's five criteria (one-star review of an everyday essential, sharpest true grievance, deadpan held, turn in the last few words, tight and specific):

> "One star. Falls from the sky for free and still shows up in my bill every single month."

The program scores every candidate, picks the highest (tie-break: shorter, then earliest), validates the winner (1–160 characters, one line, no exclamation marks), and writes it to `/output/entry.txt`. Fully deterministic — two runs produce byte-identical output.

## Run it

```sh
node main.ts
```
